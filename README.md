# California Housing ML Pipeline

End-to-end machine learning pipeline for predicting house prices using the California Housing dataset.

This project focuses on correct data preprocessing, feature engineering, stratified sampling, and realistic evaluation using cross-validation.

## Features
- Stratified train-test split based on income categories
- Feature engineering with ratio-based variables
- Median imputation for missing values
- Pipelines and ColumnTransformer
- Linear Regression baseline
- Random Forest model with cross-validation

## Evaluation
- Cross-validation RMSE
- Train and test RMSE
- Test R² score

## Tools & Libraries
- Python
- pandas, numpy
- scikit-learn
- Google Colab
